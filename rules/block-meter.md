# Super-Block Meter

[Правила](README.md)

Индикатор содержит восемь секций. Обычное повреждение героя случайно добавляет одну, две или три. При заполнении срабатывает блок очередного подходящего повреждения и выдаётся оставшаяся суперсила. За матч обычный набор ограничен тремя блоками после стартовой силы. Bullseye не заряжает блок и не даёт обычному индикатору отменить этот урон.

Три основных решения:

- Маленькие обычные удары могут помочь противнику получить блок перед вашим большим финишером.
- Bullseye сохраняет структуру расчёта летала и особенно полезен swarm-пакетам, где иначе много отдельных зарядок.
- Десять карт в руке мешают блокировать: нельзя считать полный meter гарантией выживания при переполнении.

Блок, немедленная бесплатная сила и её сохранение меняют последовательность следующих атак. Летал Espresso/Cowboy/Trickster рассчитывайте по каждой атаке, а не простым сложением номинальной атаки. Shieldcrusher Viking очищает meter после реального попадания, Body-Gourd наполняет свой, Gargolith крадёт секции; ни один из этих эффектов не отменяет остальные ограничения.

Равновероятные независимые прибавки 1–3 можно использовать для учебного вероятностного расчёта, но нельзя объявлять гарантией будущих результатов RNG. [Источник](https://plantsvszombies.wiki.gg/wiki/Super-Block_Meter).
