# Механики и timing

[Главная](../README.md) · [Правила](../rules/README.md) · [Синергии](../synergies/README.md)

| Механика | Что означает | Ошибка в расчёте |
| --- | --- | --- |
| Amphibious | Разрешает water; боец также допускается на суше | Все water-посадки не получают автоматически свойства ground-среды |
| Team-Up | Разрешает парную plant-линию | Не даёт трёх растений и не делает обычного зомби Team-Up |
| Bullseye | Урон этой карты не заряжает обычный блок | Admiral damage не становится Bullseye из-за стоящего рядом Astro |
| Anti-Hero N | Дополнительная атака при атаке героя без blocker | Число не обязательно действует в размене с бойцом |
| Armored N | Снижает каждое входящее повреждение на N до нуля | Не отменяет Destroy, bounce или stat-debuff |
| Deadly | Положительное повреждение бойца уничтожает его | При нулевом damage из-за брони убийство не обещается; нет мгновенного убийства героя |
| Strikethrough | Атака проходит по бойцам линии и герою | Блок героя и события damage всё ещё считаются |
| Splash Damage N | Фиксированные повреждения соседним линиям при атаке | Fertilize не превращает Splash 4 в Splash 8 |
| Frenzy | После уничтожения противника своей атакой выживший зомби получает дополнительную атаку | Не любое уничтожение способностью даёт Frenzy-удар |
| Double Strike | Дополнительная регулярная атака при выполнении условий боя | Гибель в первом обмене мешает следующему удару |
| Overshoot N | Повреждение герою перед боем этой линии | Отдельный damage учитывает блок; не равен Attack бойца |
| Gravestone | Скрытое тело раскрывается после Plant Play | Надгробие не делает каждый effect Trick-ом; Blockbuster работает до раскрытия |
| Hunt | Следует в линию последнего нового вражеского бойца, если перемещение допустимо | Занятая линия и выбор посадки противником ограничивают движение |
| Untrickable | Защита от вражеских трюков | Pogo/Jelly/Cob/Shover — способности существ, не тот же целевой трюк |
| Freeze | Пропускается следующая атака; бонусная атака может потратить Freeze на разморозку | Бонусный приказ не всегда даёт дополнительное повреждение |
| Draw | Карта из текущей колоды | Не равен Conjure, не достаёт любую карту по желанию |
| Conjure / Gain | Новая карта в руку из заданного пула или конкретная карта | Не бесплатный выход на поле |
| Shuffle | Копии помещаются в колоду | Не немедленный Draw и не мгновенный Dino-Roar |
| Dino-Roar | Реагирует на получение карты в руку | Подмешивание в колоду само по себе не получение карты |
| Evolution | Разыгрывание поверх подходящего бойца ради дополнительного эффекта | Требование типа/Team-Up должно быть выполнено; съеденное основание не остаётся дополнительным blocker |
| Fusion | Следующий боец поверх Fusion-основания получает указанный бонус | Не бесплатный боец и не автоматическая Evolution любого типа |
| Bounce | Возврат в руку, обычно сброс board-only усилений | On-play способности при следующем выходе могут помочь противнику; отдельные карты имеют исключения |
| Transform | Изменение бойца в другую карту | Сохранение конкретных статов/способностей зависит от эффекта, не универсально |

## Различайте типы событий

`When played`, `When revealed`, `When hurt`, `When destroyed`, `Start of turn`, `End of turn` — отдельные события. MUG повторяет раскрытия, но random-перемешивание меняет линии. Destroy не обязан активировать When hurt; смерть срабатывает отдельно. Make/Transform иногда активируют play-подобные триггеры в особых комбинациях: для редкого сложного случая нужна индивидуальная проверка, а не общее предположение.

При конфликте состояния и текста эффекта сначала смотрите конкретную карту. Например Swimmer копирует только Strength/Health, а не traits; Uncleared Freeze и Wing-Nut требуют отдельного расчёта дополнительных атак. У Nibble описан баг softlock на некоторых death-effects: он не используется в наших планах победы.
